# 最终boss 自适应智能体

## boss能力：

游戏内玩家的操作交互会被记录以作为BOSS选择特性使用，记录的内容有以下几点：
1. 玩家的受击频率：玩家被弹幕击中的频率
2. 玩家的走位习惯：玩家在面对弹幕袭来时的反应速度、走位方向倾向性。
3. 玩家的移动习惯：玩家移动时的方向倾向性
4. 玩家释放主动技能的习惯。
5. 综合评分来评价玩家强度。

在最终boss前，玩家会遇到一个血量较高的精英怪，在这场战斗时会记录玩家的DPS

最终boss的基础形态是比玩家稍大的碰撞模型，按照标准攻速发射标准弹幕，拥有近战功能并逐渐靠近玩家。
最终boss会根据以上数据，做出以下改变：
1. 改变移动模式，根据玩家的走位和移动习惯来改变移动模式。
2. 弹幕攻速和伤害，根据玩家生存能力（按照受击频率和最终玩家的血量护甲来判断）修改。
3. 自身血量和护甲，根据玩家dps修改，有上下限。
4. 在N个特性里选择5个给予自身增益。

## boss特性

boss会选择特性来适配玩家。

1. 适应力护甲：

* 维护一个tag抗性列表，受到伤害时根据伤害tag抗性减免伤害，该伤害拥有的tag的抗性增加，最高80%，随时间降低，最多维护3个tag抗性，有更多tag伤害时清除最早的抗性。

* 当玩家的攻击频率较高时更容易获得
* 玩家伤害类型较多时容易获得

2. 预判弹幕（分为三个等级）

* boss的弹幕发射方向会根据玩家走位进行预判

* 玩家评分中等以上时必定获得
* 玩家受击较少时任意获得
* 根据玩家评分和受击能力有三种模式的预判，玩家越强预判能力越强

3. 全屏弹幕（分为三个等级）

* boss偶尔发射全屏弹幕

* 玩家走位能力越好越容易获得，等级越高

4. 奇偶炮（分为三个等级）

* 连续的奇数弹和偶数弹发射

* 玩家评分越高越容易获得，等级越高

5. 闪身能力

* boss会偶尔闪身躲避弹幕

* 玩家评分越高越容易获得

6. 缓慢分裂弹

* 发射一颗缓慢弹幕，飞行一段时间后分裂

* 玩家评分越低越容易获取

7. 缓速区域

* 发射弹幕在地面上留下缓速区域

* 玩家移动速度越高越容易获取

8. 召唤小怪

* 偶尔召唤随从

* 玩家评分越低越容易获取
