# Deep Net Dungeon

roguelike平面策略弹幕射击游戏游戏，特点如下：

1. 层级可自由探索类随机地图
2. 简单易懂的局内战斗操作
3. 拼装式随机道具
4. 隐藏内容

游戏内容：

1. 游戏背景：
    
    你被一股神秘的力量拽进了网络空间，你需要探索、寻找装备、逃出这里，或者从蛛丝马迹之中找出事情的真相。
    
2. 游戏玩法：
    
    游戏是弹幕射击肉鸽地牢，玩家控制的角色自动进行攻击，玩家只负责控制移动。除去隐藏房等特殊房间，一共有五种房间，分别是商店普通房间、商店房间、资源房间、初始房间和BOSS房间。
    在初期版本里，地图是固定样式的，首先玩家从初始房间开始，走一条直线有N个普通房间，固定位置的普通房间会多一条支路通向其他房间，比如靠近初始房间的普通房间会通向资源房间，靠近BOSS房间的支路会通向商店房间。普通房间会有多波次的刷怪，击败所有敌怪即可开启通往下一个房间的门。商店房间会出现物品交易，资源房间会给一些道具，BOSS房间击败boss后会出现通往下一层的门。
    
3. 游戏流程：
    
    游戏一开始关卡共有三层，每层有一个boss，击败boss会获得一个随机的特殊道具并可以前往下一层，首次击败第三层boss之后解锁第四层，之后基础关卡就只有四层。
    
    玩家通过击败不同的boss，完成不同的里程碑来解锁组件和道具。这些都是传统的roguelike游戏流程
    
    与之不同的是，游戏有一个隐藏系统，首次击败第四层boss之后，玩家将在前三层看到隐藏房间，完成隐藏房间的解密之后玩家会进入剧情层，剧情层有一个单独的boss，击败boss之后玩家将解锁角色系统，从此可以选择角色。注意的是隐藏房间需要特殊道具触发，并不能简单的发现。
    
    解锁角色系统之后，玩家可以在角色系统里查看每个角色的解锁条件，同时开放第五层，玩家将迎接游戏的最终boss。
    
4. 游戏剧情
    
    许多年前一个神秘的组织进行了一场实验，他们在网站里部署了一个能连接到另一个空间的服务，通过这种方式对异空间进行观察，后来出现了意外，异空间的一些存在察觉到了这件事，组织紧急关闭了 网站，但是多年之后该网站又被开启，主句正是被该网站带到了异空间和网站的交界地带。主角的肉身以及湮灭，留下的只有一串数据被吸入到了网站里，所以主角是永远无法逃离网站，这也是为什么玩家通关第三层之后会被重置并返回第一层。在不断的轮回中主角找到了网站的漏洞，在漏洞里主角看到了当时网站的设计师之一W，W是该项目的负责人之一，在项目被关闭时和主角一样被吸入到了异空间的边界，由于没有时间概念，W在这里度过了数万年的时光，几乎成为了一个扭曲的异构体。在隐藏关卡里，主角打破了W给自己构建的数据壁垒，从而将W放出来成为可选角色之一。在主角线的第五层结局，主角对战完全异构体化的W，将W从数据海中完全清除，并获得了网站的后台密钥。在W线的最终结局里，W将被数据污染的主角吞噬，试图突破网站的限制，但是最终还是被重置。两个结局结束后，解锁角色观察者，探索者是异空间的存在，它检测到了该网站发出的异常波动，于是进入网站内部进行检修。探索者拥有很强的实力，它的关卡也是分为五层，在探索者的结局里，它在第三层的隐藏房间里找到了几乎要小时的主角，从主角手中接过了密钥，最后在第五层击败了网站安全防护机制，使用密钥进入了网站后台，在后台里回滚了整个网站，W从异构体恢复到了人类的模样，但是肉体已经消失殆尽，W成为了一个网络幽灵，从网站逃离之后在整个互联网上游荡。主角从电脑前醒来，望着屏幕中网站无法连接的字样，游戏正式结局。结局之后玩家可以以“查看网站备份记录”的名义仍然可以游玩三个角色进行闯关。
