# 道具编写规范

> 适用范围：`Resource/v1/Item/Data/` 下的所有 `ItemData` 资源

## 一、新道具默认进商店池

新做的道具，默认要加进 **`Resource/v1/Item/ItemPool/shop_pool.tres`**（所有关卡的商店共用这个池子），不需要额外说明。

只有明确要求"只出现在特定层"时，才另开一个池子（例如 `shop_pool_level3.tres`）并把对应房间指过去。

## 一之一、Boss 房道具池

**`Resource/v1/Item/ItemPool/boss_pool.tres`**：Boss 房通关掉落用的池子，目前收录**所有 `itemLevel = 3` 的道具**，权重统一 1。

规则：以后新增三级道具，除了进 `shop_pool`，也要同步加进 `boss_pool`（两个池子各一条）。

另外两个池子：

| 池子 | 用途 |
| --- | --- |
| `room_pool.tres` | 普通房间通关掉落（目前只有 1 级道具，权重 4） |
| `treasure_pool.tres` | 资源房间掉落（1 级权重 4、2 级权重 2） |

`get_fire` / `get_virus` / `get_collapse` 是测试效果用的道具，**不放进任何池子**。`item_xst` 是彩蛋道具，保留在 `shop_pool`（权重 1）。

## 二、商店池权重按道具等级

| `itemLevel` | 权重 |
| --- | --- |
| 1 | 4 |
| 2 | 2 |
| 3 | 1 |

例：等级 2 的「裂罅图腾」→ `ExtResource("... rift_totem.tres"): 2`。

（4 级目前还没有道具，等有需要再约定；先按 1 处理。）

## 三、池子里加条目的写法

1. 在 `shop_pool.tres` 顶部加一条 `ext_resource`：
   ```ini
   [ext_resource type="Resource" uid="uid://..." path="res://Resource/v1/Item/Data/.../xxx.tres" id="28_xxx"]
   ```
   道具资源还没有 uid 时可以先只写 `path`（Godot 保存时会补全），但优先用 uid。
2. 在 `pool = Dictionary[Object, int]({ ... })` 里加一行 `ExtResource("28_xxx"): 权重,`（最后一个条目不要留逗号）。

## 四、主动道具（`tags = [6]`）的额外约定

- 冷却时间写在 `args["cd"]`（秒），`Bag.Update` 会读它来驱动 HUD 冷却圈。
- 效果写在 `onUse` 行为里，行为放在 `Resource/v1/Item/ItemBehaviorLevel1.cs`（一个方法一个行为）。
