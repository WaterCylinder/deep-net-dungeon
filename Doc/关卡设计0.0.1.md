# 关卡设计v0.0.1

## 流程设计

游戏有三层，第一层有5个房间，第二层和第三层有十个房间，每个房间有多个轮次生成怪物，击败房间里所有的怪物可以进入下一个房间。
除了生成怪物的房间，还存在商店房间和资源房价会给玩家一些道具。
击败boss房间的boss之后会开启进入下一层的传送门
击败第三层的boss之后游戏结束。

## 敌怪设计

### 第一层

1. 电脑怪（近战）
头上顶着一个电视的怪物，电视屏幕里是愤怒的emoji，会以比较慢的速度靠近玩家，造成近战伤害

2. 电脑怪（远程）
和近战版本类似，emoji改成笑哭的emoji，会发射远程弹幕攻击玩家。
会和玩家保持一定距离。

3. 符号团
一团杂乱的代码符号，会以特殊方式移动，发射三发弹幕攻击玩家

4. 神秘立方体
漂浮的立方体怪物，行动迟缓，偶尔蓄力冲向玩家，造成近战伤害

5. boss：裂罅守卫
一个破碎的网页子页面，会在场地里反弹移动，有三种弹幕模式：
- 线性弹幕：向一个方向发射直线弹幕
- 环形弹幕：向一个方向发射环形弹幕
- 随机弹幕：向随机方向发射弹幕

第二层和第三层先用第一层的怪物

## 道具设计

道具有四个等级，等级越高道具越强，其中四级道具是特殊道具需要特殊方式获得，暂时不设计四级道具

1. 一级道具

- 尖锐箭头
图标是发光的鼠标箭头，增加少量攻击力

- 燃烧箭头
图标是燃烧的鼠标箭头，使弹幕附带火焰效果

- 数据屏障
图标是护盾，增加少量护甲值

- 能量特饮
图标是饮料罐，回血并增加少量最大生命值

2. 二级道具

- 双倍箭头
图标是两个箭头，弹幕变为双发

- 准心
图标是药片，持有时给玩家集中buff
集中buff会使玩家弹幕击中敌怪时获得少量攻击力增幅，增幅会在一段时间内逐渐减退，直到玩家再次击中敌怪。
增幅有增加上限。

- 冰冻箭头
图标是寒冰箭头，使弹幕附带冰冻效果

- 恢复芯片
图标是芯片加绿色十字图标，持有时给玩家恢复buff
恢复buff会在玩家附近没有敌怪时缓慢恢复血量。

3. 三级道具

- 防火墙
图标是防火墙，给予玩家少量护甲值提升和少量最大生命值提升，持有时获得防火墙buff
防火墙buff使玩家获得伤害减免

- 通讯模块
图标是通讯模块，使玩家的弹幕变为特殊弹幕，弹幕伤害倍率提升，同时可以穿透敌怪和障碍物。

- 404标签
图标是404标签，使玩家获得404buff
404buff会在玩家周围生成环绕物攻击敌人

## 房间设计

房间均为方形房间，左上角为返回门，房间右侧有两个左右前进门。
